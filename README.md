# Mega Gooooooooooooooooooooooooooooooooooooooooooooooooooooooooooooood Game

This project is a Roblox game script that creates a mega gooooooooooooooooooooooooooooooooooooooooooooooooooooooooooooood game experience. It includes scripts for game logic, player events, game events, player controls, and a scoreboard GUI. The game features a main game loop, player join and leave events, game start and end events, and basic player controls.

## Install

1. Open Roblox Studio.
2. Create a new Roblox game or open an existing one.
3. Place the following scripts in the specified locations:
   - **ServerScriptService/MegaGooScript.server.lua**: Main game logic
   - **ReplicatedStorage/Events/PlayerEvents**: Player-related events
   - **ReplicatedStorage/Events/GameEvents**: Game-related events
   - **StarterPlayerScripts/PlayerControls.client.lua**: Player controls
   - **StarterGui/GameUI**: Game UI elements

## Use

1. Run the game in Roblox Studio.
2. Players can join the game and see the scoreboard.
3. Use the W, A, S, and D keys to move the player character.
4. The game will log player join and leave events, as well as game start and end events.
